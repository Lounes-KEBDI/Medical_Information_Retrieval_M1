# LaTeX Folder - Report and Presentation

This folder contains all files related to the project report and presentation.

## Main Files

- **rapport.tex**: Complete project report in LaTeX format (ACM format)
- **NLPslides.tex**: Beamer presentation of the project
- **rapport.pdf**: Compiled version of the report
- **report.pdf**: Copy of the report PDF
- **references.bib**: Bibliography automatically generated by `rapport.tex`

## LaTeX Auxiliary Files

The following files are automatically generated during LaTeX compilation:
- `rapport.aux`, `rapport.bbl`, `rapport.blg`, `rapport.fdb_latexmk`, `rapport.fls`, `rapport.log`, `rapport.out`, `rapport.synctex.gz`

These files can be deleted and will be regenerated during the next compilation.

## Compilation

### Report (with bibliography)

The report uses `filecontents` to automatically generate `references.bib`. You need to compile **multiple times** to resolve all references:

**Method 1: Manual compilation (recommended)**
```bash
# Pass 1: Generates references.bib and rapport.aux
pdflatex rapport.tex

# Pass 2: Compiles the bibliography
bibtex rapport

# Pass 3: Includes the bibliography
pdflatex rapport.tex

# Pass 4: Resolves all cross-references
pdflatex rapport.tex
```

**Method 2: With latexmk (automatic)**
```bash
# Clean first if previous errors
rm -f rapport.aux rapport.bbl rapport.blg rapport.log rapport.out

# Compile with force
latexmk -pdf -f rapport.tex
```

**⚠️ Temporary page at the end?**
If you see a "Temporary page!" at the end of the PDF, this is normal during the first compilation. Run `pdflatex rapport.tex` one or two more times until all references are resolved. The page will disappear automatically.

### Slides

To compile the slides:
```bash
pdflatex NLPslides.tex
# Run again once if necessary to resolve references
pdflatex NLPslides.tex
```
